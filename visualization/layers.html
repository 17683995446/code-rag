1

Base Layer 基础层

提供系统级基础设施支持

logging_and_diagnostics.py - 诊断日志系统，带优雅降级
configuration_and_settings.py - 配置管理与设置
security_and_access_control.py - 安全与访问控制
performance_monitoring.py - 性能监控组件
2

Data Layer 数据层

处理数据存储、IO、解析、缓存

code_parser_and_document_processor.py - 代码解析器，MIN_CHUNK_SIZE=50
data_input_and_output_handler.py - 数据IO处理
caching_and_in_memory_cache.py - LRU缓存系统
backup_and_version_control.py - 备份与版本控制
data_repository_and_storage.py - 数据存储抽象
3

Processing Layer 处理层

文本分块与预处理

text_chunking_and_preprocessing.py - 文本分块器
code_cleaning_and_normalization.py - 代码清洗与标准化
4

Search Layer 搜索层

BM25搜索与混合搜索，增强的相关性算法

bm25_search_engine.py - BM25搜索引擎，同义词扩展+模糊搜索+位置权重+密度得分
hybrid_search_and_ranking.py - 混合搜索与排序
5

RAG Engine RAG引擎层

生产级Embedding、向量索引、多后端LLM

embedding_production.py - 生产级Embedding，Sentence-Transformers集成
vector_index_production.py - 生产级向量索引，FAISS集成
llm_production.py - 多后端LLM引擎（OpenAI/Anthropic/Local/Rule）
language_model_and_answer_generator.py - 语言模型与答案生成
retrieval_pipeline_processor.py - 检索流水线处理
semantic_search_evaluator.py - 语义搜索评估器
6

Observability Layer 可观测层

Prometheus监控、追踪、指标收集

prometheus_monitoring.py - Prometheus监控
distributed_tracing.py - 分布式链路追踪
metrics_collection_and_exposure.py - 指标收集与暴露
7

Service Layer 服务层

业务逻辑服务

code_search_service.py - 代码搜索服务
question_answering_service.py - 问答服务
8

Middleware Layer 中间件层

认证、限流、日志

authentication_and_authorization.py - 认证与授权
rate_limiting_and_throttling.py - 速率限制与节流
9

API Layer API层

REST API端点

rest_api_endpoints.py - REST API端点，带优雅降级
