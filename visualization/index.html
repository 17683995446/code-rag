真实的Embedding

简单解释： 把代码转换成数字向量（想想GPS坐标），让计算机能理解相似的代码片段。

技术特点： 集成 Sentence-Transformers，自动GPU加速，内置LRU缓存。

from code_rag.rag_engine import ProductionEmbeddingEngine
embed_engine = ProductionEmbeddingEngine()
vector = embed_engine.encode("def calculate_sum(a, b)")
🎯

向量索引

简单解释： 就像图书馆的索引卡片，帮你快速找到相关的内容。

技术特点： FAISS集成，支持多种索引类型，自动优雅降级。

🤖

多后端LLM

简单解释： 就像有多个智能助手备选，一个不行换下一个！

技术特点： 支持OpenAI、Anthropic、本地模型，还有智能规则引擎兜底。

⚡

混合搜索

简单解释： 既找关键词（Google搜索），又找语义（像人的理解）。

技术特点： BM25关键词搜索 + 向量语义搜索，智能结果融合排序。

🛡️

优雅降级

简单解释： 即使缺少依赖，系统依然能工作！

技术特点： 完整的try-except优雅降级处理。

📊

可观测性

简单解释： 监控系统的心跳和健康状况。

技术特点： Prometheus监控，分布式链路追踪。

🎯 我们是如何让搜索更准确的？

📏

代码块过滤

只保留50字符以上的有意义内容，避免空文件和小片段干扰。

MIN_CHUNK_SIZE = 50
🔤

同义词扩展

理解"function" = "method"，"config" = "configuration"，自动扩展查询。

25+组同义词
📍

位置权重

代码开头的关键词更重要（权重+30%），中间也加分（+10%）。

📈

密度得分

匹配的关键词越多，得分越高（每匹配+0.2分）！

🔄

模糊搜索回退

没找到精确匹配？没关系！自动尝试模糊、前缀、子串搜索！
